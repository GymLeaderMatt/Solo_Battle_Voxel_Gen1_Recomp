# Disclaimer
- This was made for a 1080p monitor in mind. If you try this on mobile or handheld, it'll look awful but you do you.

# What is this?
- I was tired of the voxel mod shuffle so I basically took the original mod, some tweaks from some other mods, and made my own.
- Voxel in the overworld isn't my priority. It's just there. I personally do not play with it on. The main focus was battles.

# Main Features:
- Contains a generated gradient background and a 'disc' system.
- These change depending on where you are and outdoor location background changes depending on the time of the day.
- The screenshot is at dusk in Viridian Forest, just for an example. If you were in Silph, it would have its own custom disc/backdrop.
- I resized the nameplate/health huds. I swapped my Pokemon to be in the top left due to my overlay and changed the enemy to be the bottom right.
- These are resized smaller so that I can create masks in videos without it messing anything up and to keep things minimal and tidy.
- My Pokemon mods also depend on this. I added the ability to use bigger sprites without them being shrunk to the point they lose all of their detail. This allows me to use some really high fidelity sprites for custom Pokemon and it is absolutely required if you run those.
- As of now, Mega Rayquaza is the only Pokemon I have made that needs this. If more are added, I will not remember to update but will put this link in the description.

# Other Changes:
- I find the auto updates and the insistence to put the options for this mod in the 'main' options category. It got to where it felt like I have 72 added options.
- Some of the voxel stuff still exists in the main menu but all of the battle options exist in the in-game mod folder under those options to keep things a little neater.
